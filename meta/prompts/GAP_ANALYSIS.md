# Prompt - Curriculum Gap Analysis

Syllabus، official docs/reference indexes، specs و source-tree inventory را compare کن.

برای هر gap احتمالی تعیین کن:
- missing واقعی است یا در owner دیگری پوشش دارد؟
- core/advanced/legacy/product/implementation است؟
- prerequisite چیست؟
- module جدید لازم است یا subtopic؟
- کدام downstream docs affected می‌شوند؟

نتیجه را با evidence و proposed ID/owner ارائه کن؛ بدون evidence syllabus را inflate نکن.
