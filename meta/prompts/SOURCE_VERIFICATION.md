# Prompt - Source Verification Pass

Draft را claim-by-claim audit کن:

- stable fundamental / version-sensitive / normative / implementation-specific را label کن؛
- برای هر claim حساس source مناسب وجود دارد؟
- version/date/default/deprecationها current هستند؟
- spec و implementation با هم اشتباه نشده‌اند؟
- inference به‌عنوان inference علامت خورده؟
- disagreement پنهان نشده؟
- citation واقعاً همان claim را support می‌کند؟

Unsupported claim باید اصلاح، محدود یا `Unresolved` شود.
