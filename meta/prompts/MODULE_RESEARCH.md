# Prompt - Module Research

Document ID و Scope Contract را بگیر. قبل از draft:

- authoritative source set را pin کن؛
- research questions ایجاد کن؛
- terminology/invariants را استخراج کن؛
- happy path و state transitions را evidence-map کن؛
- internals و boundaryها را تا عمق تعریف‌شده بررسی کن؛
- failure modes و observable signals را جمع کن؛
- source/spec reading path طراحی کن؛
- labs باید mechanism را expose کنند، نه صرفاً command tutorial باشند؛
- unresolved items را جدا کن.

خروجی research dossier باید claim/evidence mapping داشته باشد و هنوز PDF prose نهایی نباشد.
