# Prompt - PDF Generation

این prompt مستقل نیست. **ابتدا `MASTER_PDF_PROMPT.md` را کامل اجرا کن.**

بعد این قانون‌ها را هم بدون استثنا اجرا کن:

1. متن فارسی را ساده، روشن و طبیعی بنویس. موضوع فنی می‌تواند عمیق باشد، اما جمله‌ها نباید سنگین و پیچیده شوند.
2. فونت فارسی Vazirmatn باشد و embedding واقعی آن بررسی شود.
3. **فاصله واقعی محتوای اصلی تا کادر صفحه باید در هر چهار سمت حداقل 20mm باشد.** فقط به عدد CSS اعتماد نکن؛ خود PDF نهایی را بررسی کن.
4. تنظیم پیش‌فرض A4 برای رسیدن به این فاصله واقعی: **22mm در بالا، چپ و راست و 24mm در پایین**.
5. هیچ متن، جدول، باکس، تیتر یا شکل نباید نزدیک کادر صفحه دیده شود. اگر فاصله کم است، layout را اصلاح کن؛ اندازه فونت را بی‌دلیل کوچک نکن.
6. بعد از ساخت PDF، فاصله واقعی متن تا کادر را به‌صورت ماشینی بررسی کن و سپس همه صفحات را با 180 تا 220 DPI render کن.
7. در Visual QA، فاصله محتوا تا کادر را در کنار RTL/LTR، فونت، جدول‌ها، footer، TOC و شکست صفحه بررسی کن.
8. اگر حتی یک صفحه فاصله کمتر از 20mm، clipping، شلوغی یا خوانایی بد دارد، PDF نهایی نیست. source را اصلاح کن، دوباره PDF بساز و همه صفحات را دوباره بررسی کن.
9. فقط candidateای که تمام بررسی‌ها را پاس کرده می‌تواند canonical شود.
