# Copyright and Library Policy

`library/` یک catalog است، نه مخزن کتاب‌های دارای copyright.

- کتاب تجاری فقط وقتی commit می‌شود که license/permission صریح اجازه دهد.
- برای کتاب خریداری‌شده فقط metadata، edition، ownership note و local/private location hint ثبت شود.
- docs/specs open-source نیز قبل از mirror شدن license بررسی شوند؛ link + version pin اغلب بهتر است.
- quote طولانی ممنوع؛ synthesis و paraphrase اصل است.
- font binaries هم طبق policy پروژه commit نمی‌شوند و با workflow pinned تهیه می‌شوند.
