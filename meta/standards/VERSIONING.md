# Versioning Policy

## Documents

Semantic-like versioning:

- MAJOR: تغییر scope/architecture سند که learning contract را می‌شکند.
- MINOR: اضافه شدن coverage مهم یا تغییر source baseline با محتوای جدید.
- PATCH: اصلاح typo/layout/citation یا factual fix محدود بدون تغییر scope.

## Status

`draft -> reviewed -> canonical -> superseded/deprecated`

## Research cutoff

Research cutoff version نیست؛ تاریخ آخرین verification است. هر document version باید cutoff خودش را ثبت کند.

## Generated PDF

نام source و PDF باید version یکسان داشته باشند. PDF بدون matching source معتبر نیست.
