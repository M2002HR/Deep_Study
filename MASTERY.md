# Mastery Definition

## Definition of Done مشترک

یک module وقتی mastered محسوب می‌شود که learner بتواند:

- بدون note مسئله و مفهوم را دقیق توضیح دهد؛
- diagram/state model اصلی را از حافظه بکشد؛
- happy path را مرحله‌به‌مرحله trace کند؛
- حداقل یک lab سالم را از صفر اجرا و explain کند؛
- failureهای اصلی را classify و debug کند؛
- boundaryها و dependencyها را با مفاهیم مجاور توضیح دهد؛
- reference مناسب برای operation ناشناخته را سریع پیدا کند؛
- پاسخ‌های ۳۰ ثانیه، ۳ دقیقه و ۳۰ دقیقه ارائه کند؛
- به شریک مطالعه teach-back کند و boundary questionها را پاسخ دهد.

## Gates عمیق‌تر

### Internals Gate

- حداقل یک mechanism را بدون abstraction ابزار بازسازی/observe کند؛
- relevant spec یا kernel/runtime primitive را بخواند؛
- حداقل یک source path را trace کند.

### Contributor Gate

- repository را build/test کند؛
- issue واقعی را reproduce کند؛
- test یا patch کوچک قابل review آماده کند؛
- design/trade-off را از source و project conventions دفاع کند.

## Evidence

mastery صرفاً checkbox نیست. برای moduleهای مهم evidence می‌تواند شامل lab log، diagram، incident write-up، interview recording/notes، source trace یا PR باشد.
