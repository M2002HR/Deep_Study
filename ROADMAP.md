# Deep Study Roadmap

این roadmap عمداً high-level است؛ ترتیب واقعی از dependency graph هر curriculum می‌آید.

## Track 01 - DevOps / Systems

- Docker Mastery - active
- Linux Systems - extracted/deepened alongside Docker
- Networking - extracted/deepened alongside Docker
- Git - future deep specialization
- CI/CD - future
- Kubernetes - after container/Linux/network foundations reach required gates
- Observability/SRE - future
- Infrastructure as Code / Terraform - future
- Cloud platforms - future
- Security - cross-cutting and future specialization

## Future tracks

- Backend and distributed systems
- Algorithms and data structures
- Operating systems

- Programming languages/compilers
